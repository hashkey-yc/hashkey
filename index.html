怎么预览

双击 index.html 用浏览器打开即可，无需安装任何依赖。

怎么走流程

  1. 安全设置 → 高级设置 → 防钓鱼码（未设置）
  2. 展开/收起说明，填写防钓鱼码，如 SafeWord
  3. 点「确认」→ 安全验证 → 手机号码或邮箱
  4. 输入验证码：123456 成功，其他为失败
  5. 连续 3 次错误 → 验证失败结果页
  6. 成功后回列表，状态变为已设置，再次进入即为「修改」

键盘

Tab / Shift+Tab 在可点元素间移动，Enter 触发，Esc 关闭弹层，验证码框支持粘贴与退格。
